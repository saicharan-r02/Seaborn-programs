# Seaborn Daily Practice Archive

This directory contains foundational exercises, chart prototypes, and visualization experiments using Seaborn and Matplotlib:

- **Iris Dataset Pairplots**: Multidimensional pair-wise scatter and KDE grids (`Iris.py`).
- **Joint Distributions**: Bivariate relationships with marginal distributions (`Joint.py`).
- **Heatmaps & Correlation**: Matrix heatmaps with colorbars and annotations (`heatM.py`, `PD.py`).
- **Statistical Plots**: Distribution curves, count plots, and bar visualizations (`sns.py`, `NEW.py`).
- **Generated Figures**: Complete collection of practice PNG plot outputs.
